1. CONNECT TO OBS

In OBS: Tools → WebSocket Server Settings → tick "Enable WebSocket server". Copy the port and password here.

2. PICK SOURCES

Show all sources (not just cameras)
The new text source is added to the scene that is live in OBS. Place it in the scoreboard's clock cut-out and style the font in OBS.

Sending: OFF
The time is only sent to OBS on this computer. It never uses Firebase.
If the camera can't be read, the last good time stays on screen (shown in red here).

4. DRAW THE CLOCK BOX

Click and drag a box around the whole clock, from the left edge of the first minute digit to the right edge of the last seconds digit. Include the blank spot even if the first digit is dark.
Below: what the reader sees. Each digit spot gets its own box. Green = segment lit, red = dark. Line the boxes up with the segments using the sliders.
